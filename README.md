# right-now

「今この瞬間」の気持ちや気分を、質問形式で入力して視覚化するランディングページ（LP）。
入力はスライダーとテキストで行い、波形グラフ、フラクタル（L-system）幾何模様、手続き生成のロールシャッハ風インクブロット、および嘘発見機風のアニメーションでイメージ化します。

ホームページ: https://watanabe3tipapa.github.io/right-now/

## 概要
- 5つの質問をスライダー（0〜100）で回答し、追加の解釈入力としてロールシャッハ風インクブロット（手続き生成）を3枚に対して入力できます。
- 回答は波形グラフとL-systemによるフラクタル模様で可視化され、結果は画像（PNG）として保存・共有できます。

## 主な機能
- 5つの質問をスライダーで回答（0〜100）
- ロールシャッハ風インクブロット（手続き生成）を3枚に対して解釈入力
- 生成中の嘘発見機風アニメーション
- 回答を波形グラフ + フラクタル模様（L-system）で可視化
- 結果共有用のURLハッシュ形式
  - 例: `#50-60-30-70-40-40-55-45`（最後の3つは各ロールシャッハ強度）
  - 旧形式も互換で読み込み可: `#a-b-c-d-e-r`（6パーツ。末尾1つを全強度に適用）
- 結果をタイムスタンプ付きPNGとして保存（ファイル名例: `right-now_YYYYMMDD-HHMMSS.png`）
- 端末共有（Web Share API）: 結果PNGとURLを端末の共有メニューから共有（対応ブラウザのみ）
- QRコード共有: 結果画像をLocalStorageに保存し、`?img=token`のQRを生成。QRを読み取ると保存画像を表示（同一ブラウザ/同一オリジン）
- 回答から生成される一言の診断文（ヘッドライン＋気分の要約）を結果画面とPNGに表示
- QRコードは CDN（jsDelivr の qrcode）を使用

## 注意・既知の制限
- LocalStorage はオリジン・ブラウザ単位です。QRコード経由で復元できる画像は同一ブラウザ・同一オリジンでのみ表示可能です。
- `?img=token` で開くと保存済み画像をライトボックス表示し、そこから再ダウンロードできます。
